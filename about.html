About & Data Sources

This project treats Messi’s career as an open dataset. Every figure on the site references the sources below, and the CSV excerpt is kept in the repository for reproducibility.

Last dataset fetch: --

Primary stats (goals, assists, minutes, shot locations) come from FBref and WhoScored, with xG/xA supplied by Understat. Transfermarkt validates competition names, match counts, and trophy tallies, while the MessiVsRonaldo Gatsby feed provides consolidated historical breakdowns.


Numbers are normalized to per-90 where possible, computed via a Node script located in scripts/fetch-mvsr-data.js. Every run writes to data/mvsr-data.json and stamps the fetch date you see above. This file hydrates counters, tables, and charts throughout the site.
